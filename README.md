# Florart: демо концепта сайта

Интерактивный демо-вариант концепта сайта цветочного ателье Florart (Кишинёв). Это инициативный концепт, а не официальный сайт и не замена florart.md.

Откройте демо: https://lordfour.github.io/florart-demo/

В этом репозитории только собранная статическая версия сайта. Исходные файлы здесь не публикуются.

## Что в демо

- Главная, каталог с фильтрами, карточка букета, корзина, демо-оформление.
- Florart Moments, персональный флорист, ателье, Florart Business, политика конфиденциальности.
- Три языка: RU, RO, EN.

## Чего в демо нет

- Оформление заказов, отправка форм и писем не работают: всё только показывает демо-статус.
- Адрес салона и часы работы не найдены на florart.md и помечены как уточняемые.
- Фото композиций взяты с florart.md. Их публичная демонстрация не согласована с владельцами сайта. Если владельцы против, фото нужно заменить или удалить.
